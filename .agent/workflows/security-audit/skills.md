# SKILLS : WORKFLOW SECURITY-AUDIT

Skills prioritaires pour ce workflow :
- `security-review` : Audit des schémas d'authentification, injection d'entrées et secrets.
- `review-security` : Sous-agent spécialisé en audit de code et détection de vulnérabilités.
- `quality-gate-audit` : Validation formelle des critères de sécurité fintech.
