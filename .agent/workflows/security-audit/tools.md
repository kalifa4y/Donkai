# TOOLS : WORKFLOW SECURITY-AUDIT

Outils autorisés :
- `view_file` : Examen des politiques de sécurité et des flux sensibles.
- `grep_search` : Recherche de fuite de tokens, clés ou variables d'environnement exposées.
- `replace_file_content` : Application des correctifs de sécurisation.
- `run_command` : Exécution de scripts d'audit et tests de régression.
