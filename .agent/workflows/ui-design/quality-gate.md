# QUALITY GATE : UI-DESIGN (DONKAI)

- [ ] **Plan approuvé par Kalf** avant modification.
- [ ] **Typographies respectées** : `Cal Sans` pour titres et chiffres clés, `Google Sans Flex` pour le texte et les boutons.
- [ ] **Palette tellurique appliquée** : Pas de dégradés violet/bleu génériques d'IA.
- [ ] **Zéro Emoji** : Strictement aucune icône emoji, présence exclusive d'icônes SVG Lucide.
- [ ] **Cibles tactiles mobiles** : 44x44px minimum pour tout élément cliquable/tactile.
- [ ] **Contraste accessible** : Conforme aux recommandations WCAG AAA.
- [ ] **Pas d'empilement excessif de cartes** : Hiérarchie par l'espace blanc et la typographie.
- [ ] **États interactifs visibles** : `:hover`, `:focus-visible`, `:active`, `:disabled` expressément stylisés.
