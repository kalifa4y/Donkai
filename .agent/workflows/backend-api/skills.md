# SKILLS : WORKFLOW BACKEND-API

Skills prioritaires pour ce workflow :
- `backend-patterns` : Structuration propre des services backend et accès aux données.
- `api-design` : Conception REST sémantique, idempotence et gestion d'erreurs.
- `security-review` : Audit de sécurité des endpoints et contrôle d'accès.
- `tdd-workflow` : Développement piloté par les tests pour la logique métier des API.
