# TOOLS : WORKFLOW DEBUGGING

Outils autorisés :
- `view_file` : Examen du code source suspect et des traces d'erreurs.
- `grep_search` : Recherche d'occurrences d'identifiants, erreurs ou statuts.
- `replace_file_content` : Application précise du correctif ciblé.
- `run_command` : Exécution du test de reproduction et validation du build.
